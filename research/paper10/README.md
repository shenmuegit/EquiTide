# 十策略实盘行情＋模拟资金

本模块固定测试用户10行榜单的P01–P10；每组主账户2000USDT，另有2x/3x独立成本压力副本。plan.json不可变；state.json为连续账户，observations/为不可变的每轮账本。只访问Binance公开GET行情，不调用真实资金或订单接口。

每轮先在干净或已保留他人工作的研究分支运行：

```sh
.venv/bin/python research/paper10/run.py --hold-lock
```

看到PAPER10_READY_LOCK_HELD后，保留该进程持有的research/automation/branch.lock，完成必要检查、相关证据提交和非强制push。API上传亦在该锁的保护期内。确认远端完整树和SHA后，向原执行会话stdin发送release及换行释放锁；EOF也会安全释放。取不到锁时等待，不能覆盖并行任务。不要为新的轮询再次创建账户或改plan。

日线信号仅在出现新闭合UTC日线时处理一次。真实未闭合日线只作为原信号函数的未使用尾部输入，不进入决策；EMA从2025-09-16真实数据首日递推。首次所有账户从现金和desired-cash开始，不回放历史持仓。虚拟成交用本轮实际买卖报价，记录报价收取/模拟执行/信号可用时间及延迟，不用过去分钟开盘补单。

费用为每侧10bp，另计实际点差、2bp滑点与前20个闭合日波动率/quoteADV相关冲击；数量、tick和当前交易所规则检查保持。成交是即刻全额IOC模型，不能证明真实交易所接单或容量。每个策略资金独立，不合并虚拟订单冲击，也不把各策略当一只真实组合基金。

不足180天/6个30天窗口时，观察登记rejected只表示未成熟，状态继续运行。报价失败用blocked，账户不变；这些缺实际结果的paper观察不能冒充历史策略失败或被研究任务强制补成有结果。180天依据冻结门槛评估，回撤仅为实际报价快照采样口径，非分钟/逐tick风险。

恢复只提升已完整记录且审计通过的state_after；新的状态必须匹配最新完成账本。损坏或冲突时停止保留证据，不能回到新现金账户。未完成的旧报价捕获不补做订单。每轮保留真实原始响应、来源/哈希、状态前后、交易、失败、零交易及负收益。

检查与离线重放：

```sh
.venv/bin/python research/paper10/check.py
.venv/bin/python research/paper10/run.py --reproduce <观察目录名>
.venv/bin/python checks/strategy_registry.py
```

check.py默认仅运行明确标注的合成账务/时序夹具，不是业绩证据；--reproduce只核对已有真实输入/成交/状态，不HTTP、不写登记、不生成新成交。改执行器后必须保留旧版本及既有账本，先通过必要检查，不得静默重写历史。
