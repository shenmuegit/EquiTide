# 本轮远端同步失败与恢复

首个执行进程在同步远端 main 的 git fetch 阶段收到“Connection to github.com closed by remote host”，fetch 返回128、执行进程返回1。故障发生在行情获取、观察截止登记及账户推进之前；该次没有行情GET、虚拟成交、真实订单或费用扣除。原始输出完整保存在 preflight_failure.json。

随后重新运行同一执行器，远端 main 同步成功，所有9个公开行情GET均在失败留档之后实际发起，按本轮新报价形成第486个成功快照。前状态与故障留档的485次账户状态逐字节相同；60个分仓的现金、币量、成本、desired状态、已处理日线与成交ID完整延续，没有重置或补填交易。登记增加的是本轮10组reserve/finish，失败的预检未评估观察配置，故没有伪造reserve。

本轮零成交、零新增日线决策、无新增采样缺口。连接中断根因未确认；未修改执行器、冻结规则、行情端点或成本假设。旧回测与原SMA延迟shadow均不计入本次前向业绩。
