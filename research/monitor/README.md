# EquiTide 只读监控

网页展示真实 Binance 现货公开买卖报价、P01–P10 固定模拟账户及已登记的策略研究结果。只读取记录，不执行策略、不发送订单、不改变本金、权重、冻结计划或账户状态。

## 数据更新

在研究或 paper10 完成本轮登记和检查后、提交推送前，持有 `research/automation/branch.lock` 运行：

```sh
python3 research/monitor/snapshot.py
python3 checks/monitor_snapshot.py
```

将 `research/monitor/latest.json` 与 `research/monitor/configs.json.gz` 一起提交并推送至研究分支。网页每30秒检查公开分支的汇总；研究排名仅在内容哈希变化时重新下载。原任务仍约每两小时更新账户和研究证据，GitHub缓存传播可能另有短暂延迟。页面打开期间每10秒读取公开BTC/ETH买一卖一，中间价只是独立行情展示，不重估或改写模拟账户；页面隐藏或手动暂停时停止轮询。

`latest.json` 为约85KB的状态索引；研究明细使用标准gzip压缩（约0.64MB），浏览器通过原生解压和SHA256校验读取。CDN传播过程中两文件不匹配时保留已有研究榜并等待下一次刷新。已有完整原始报告是精度和复现依据，网页研究展示数字保留六位小数；账户Decimal金额原样保留。

账户只接纳 `complete.json`、`report.json`、`state_after.json` 互相哈希一致且匹配冻结计划的真实行情观察。正在写入或失败时展示最后完整观察并标明状态；不会把缺失账户显示为零。账本回撤限于实际保存报价采样，不称分钟级回撤。

研究按完整规则指纹合并等价配置，参数和权重变体分别保留。持续观察截止、十策略观察和旧SMA延迟shadow不计入策略挖掘试验数。排名默认比较2026-03-18至2026-09-14、初始2,000USDT的组合、3倍成本；其他区间与单币组件单独选择。不把缺少可比格式的历史结果填成零，也不把复用报告中的只读对照再次计数。正收益、负收益及未通过门槛的配置均保留。敏感性“已留档”指原批次有记录，不表示所有邻域通过；历史通过不代表前向验证通过或稳定盈利。

## 网页开发与检查

沿用 `web/` 的React、Vite、Recharts和字体。`web/monitor.html` 是独立入口，原历史分析入口保持；生产构建同时输出两个入口。没有后台数据库或私有API凭据。

```sh
cd web
npm ci
npm run build
```

可用 `VITE_MONITOR_FEED_URL` 指向本地只读JSON服务进行预览；默认数据源为研究分支的公开raw文件。浏览器验收：启动预览及只读数据服务后，指定本机Playwright和Chromium路径执行 `node checks/monitor_browser.cjs`。它核对真实公开报价、账本对应、收益排序、筛选、详情、移动端宽度、失败时保留余额及暂停轮询；截图留在忽略的 `data/runs/monitor-qa/`。

发布使用独立Sites源仓库，复制本目录构建所需的监控源码，静态产物托管在公网。源仓库和部署不包含原始大行情、账户密钥或真实交易入口。公开只读访问范围由用户明确选定。
